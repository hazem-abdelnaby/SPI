# SPI Master Design – Verilog HDL

## Overview

This project implements an SPI Master using Verilog HDL. The design supports simultaneous serial transmission and reception, configurable data width, clock division, and slave selection.

The design is organized into separate modules, with an FSM controlling the overall transaction.

## Architecture

The design consists of the following modules:

| Module | Description |
|---|---|
| `Top_SPI_Master` | Top-level module connecting all design blocks. |
| `SPI_Master_FSM` | Controls the transaction sequence and generates control signals. |
| `SPI_Clock_Generator` | Generates SCLK and the sampling and shifting enable signals. |
| `Bit_Counter_SPI` | Counts the received bits and indicates transaction completion. |
| `TX_Shift_REG` | Loads and shifts the transmit data to MOSI. |
| `RX_Shift_REG` | Samples MISO and stores the received data. |

## Transaction Sequence

The FSM uses five one-hot encoded states:

1. **IDLE:** Waits for `TX_Valid`.
2. **LOAD:** Loads the transmit data and resets the bit counter.
3. **ASSERT_SS:** Selects the requested slave and checks the selection.
4. **TRANSFER:** Enables the SPI clock and controls transmission and reception.
5. **DONE:** Indicates that the transaction is complete and asserts `RX_Valid`.

During the transfer:

- `TX_Shift_REG` shifts data out through MOSI.
- `RX_Shift_REG` samples incoming data from MISO.
- `Bit_Counter_SPI` counts the received bits.
- `sample_enable` and `shift_enable` are generated by the clock generator.

The transaction ends when `Count_Done` and `shift_enable` are asserted together.

## Configurable Parameters

| Parameter | Default Value | Description |
|---|---:|---|
| `Data_Width` | 8 | Number of bits transferred per transaction. |
| `number_of_slaves` | 3 | Number of supported slave selections in the FSM. |
| `COUNTER_WIDTH` | 8 | Width of the clock divider counter. |
| `DIV_VALUE` | Configurable input | Determines the generated SPI clock frequency. |

The generated SPI clock frequency is:

\[
f_{SCLK} = \frac{f_{CLK}}{2 \times DIV\_VALUE}
\]

The clock generator initializes SCLK to logic high.

## Simulation

The testbench verifies a complete SPI transaction using the following configuration:

| Signal / Parameter | Value |
|---|---|
| System clock period | 10 ns |
| `Data_Width` | 8 bits |
| `DIV_VALUE` | 4 |
| `TX_Data` | `8'hA5` |
| Expected `RX_Data` | `8'h3C` |
| `slave_select` | 0 |

The testbench checks:

- Transmitted MOSI bits.
- Received data against the expected value.
- Slave-select release after the transaction.
- Invalid slave selection status.

The testbench reports the results using `TX PASS`, `RX PASS`, and related messages.

## Interface

**Inputs**
- `CLK`, `RST`
- `TX_Valid`
- `TX_Data`
- `DIV_VALUE`
- `slave_select`
- `MISO`

**Outputs**
- `MOSI`
- `MISO` is the external serial data input.
- `SCLK`
- `SS[2:0]`
- `RX_Data`
- `RX_Valid`
- `busy`
- `Invalid_Slave_Select`

## Conclusion

The project implements a modular SPI Master with separate transmission, reception, clock generation, bit counting, and control logic. The testbench verifies the basic data transfer operation and transaction completion.
